KEVIN COSTNER INDEPENDENT FAN SITE

Folder structure:
index.html
images/
posters/

The images folder is for the public-domain Kevin Costner photographs included with this build.
The posters folder contains named placeholders so you can replace them with movie poster files you are legally permitted to use.

The website is intentionally labeled as an independent fan community and does not claim official affiliation, management, membership, booking, or representation.
